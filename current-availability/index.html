Current availability audit · 20 Sep 2026 UTC

Current Union Alpha availability: retired preview, unlisted Go alias

Audit window: 2026-09-20T07:32:44Z–2026-09-20T07:35:01Z UTC. This was a narrow route-status and attribution-scope audit. It did not include broad benchmark or rumor search, paid Pareto evaluation, account creation, subscription, purchase, an old-slug request, a load/capacity test, retry, or private-code request.

Decision brief

Current answer
Do not start a new integration on either former Union Alpha identifier. The OpenRouter preview is retired/no longer catalog-listed, and the former OpenCode Go alias is no longer listed in the inspected current Go sources. The paid Pareto route is a separate catalog listing, not a demonstrated fixed Union Alpha replacement. No request was sent (n = 0).
  1. The OpenRouter preview remains retired/no longer current-listed. The historical stealth/union-alpha page says its free stealth period ended, identifies the model as Pareto by Unbiased, and directs readers to paid unbiased/pareto. The current public catalog has Pareto but no stealth/union-alpha entry. This is catalog and historical-page evidence—not an old-ID HTTP request or a claim about any old key. R3-S01 · R3-S02 · R3-S03
  2. The R2-named Go alias is now absent from both current Go documentation and public catalog. The inspected documentation had no Union Alpha/union-alpha text, endpoint row, privacy row, or model row; the public GET /zen/go/v1/models result had no union-alpha ID. R2’s “documentation-only” route becomes no longer listed in inspected current Go sources, not “working,” “entitlement-blocked,” or an observed API error. R3-S06 · R3-S07
  3. No Go request was sent (n = 0). The prerequisites for a tiny Go request both failed: the alias was not currently documented/listed and names-only environment checks found no pre-existing Go credential. There is no request, HTTP result, latency, provider/routing field, rate-limit header, error, DNS event, or availability sample.
  4. Attribution is precise only for the former preview. OpenRouter says Union Alpha was revealed as Pareto by Unbiased; Unbiased describes Pareto as blended and says Unbiased/Pareto are built and maintained by Circuit & Chisel. No inspected source says the former OpenCode Go union-alpha alias was Pareto, identifies its composition, or maps either alias to a fixed Pareto/version snapshot. R3-S01 · R3-S09 · R3-S10
  5. Do not transfer limits, privacy, or performance across routes. The retired preview’s historical retention wording is not current Pareto policy; R2’s Go 0 days/Not used row is no longer in the current Go document; generic OpenRouter free-variant rules remain non-model-specific; page telemetry and provider-published Pareto 26.9 scores are not audit results or Union Alpha snapshot proof. R3-S04 · R3-S06 · R3-S10

What this changes for use

  • Former OpenRouter preview: do not use stealth/union-alpha for a new integration. Its historical page indicates ended/no longer catalog-listed status; no old-slug request was sent, so this page makes no HTTP-error claim.
  • Paid Pareto successor: unbiased/pareto is a separate current route, not a demonstrated immutable preview replacement. Evaluate it only with separately approved budget/access/retention review. Do not send sensitive code until current route-specific data terms are acceptable.
  • Former OpenCode Go alias: do not configure opencode-go/union-alpha from R2 instructions. If official sources re-list it, a future, separately authorized evaluation should begin with one tiny non-sensitive request and preserve its evidence; one request would still not establish capacity, reliability, quota, SLA, or equivalence.

  • If an alias is again current-listed and an authorized credential exists, what does one minimal non-sensitive request show? That observation would be n=1, not a capacity, reliability, quota, SLA, or equivalence result.
