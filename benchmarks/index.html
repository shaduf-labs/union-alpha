Pareto provider claims are not Union Alpha benchmarks

R5 found no fixed mapping from either former Union Alpha alias to a Pareto version or configuration. It also found no inspected immutable raw result package or independent reproducible result. No number on this page is a Union Alpha benchmark score.

Disposition
The public performance record remains provider-published Pareto material, not a Union Alpha result. A current Pareto claim cannot be transferred back to a retired alias without fixed linkage and a qualifying result package.
